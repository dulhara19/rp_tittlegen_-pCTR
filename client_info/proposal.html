Quotation — AI-Powered YouTube Title Optimizer
1. Project Overview

Development of an AI-powered, multi-agent system that automatically analyzes a YouTube video's content and generates psychologically optimized, virality-engineered titles — for a BSc (Hons) Software Engineering research project at NSBM Green University.

The system covers a LangChain multi-agent pipeline (Analyzer, Generator, Critic agents), a Predicted CTR (pCTR) machine learning model (Random Forest / XGBoost), an NLP evaluation layer (VADER sentiment, BERTScore, NLI faithfulness check), and a FastAPI REST backend. Built with AI-assisted tooling and scoped as a fully functional research prototype sufficient to complete and defend the thesis.

A complete thesis document covering all chapters (Introduction through Conclusion) and 8 included mentorship sessions are provided alongside the system.

2. Deliverables

Deliverable 1 — System Prototype

ComponentDetails
Analyzer AgentExtracts core video promise, key entities, emotional potential, and applicable psychological triggers from transcript / description
Generator AgentProduces 5 candidate titles per run, each targeting a different psychological trigger (curiosity gap, loss aversion, social proof, urgency, extreme framing)
Critic AgentScores candidates with pCTR model, VADER arousal check, BERTScore relevance, and NLI deception detection — auto-rejects contradictory titles
pCTR ML ModelRandom Forest / XGBoost trained on YouTube trending dataset with engineered title features
NLP LayerVADER sentiment scoring, BERTScore relevance filter, NLI faithfulness gate (prevents AI-hallucinated titles)
FastAPI BackendAsync REST API exposing the full pipeline as a clean endpoint
YouTube API IntegrationDataset collection pipeline via YouTube Data API v3
Demo & EvaluationWorking demo with ranked title outputs, evaluation metrics, and sample results
Source CodeComplete, documented — delivered via private GitHub repository
